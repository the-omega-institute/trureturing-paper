# A2 native-agent test matrix

The A2 integration is covered at three boundaries.

## Generic agent boundary

```text
immutable task registration
exact evidence materialization
phase-owned role and context
workspace-only output
single result envelope
content-addressed output admission
terminal cursor replay
```

## A2 domain boundary

```text
exact program, scope, inventory, request, and prior-package closure
five-claim theorem DAG admission
main theorem, sharpness theorem, and classification corollary
repository-computed new and strengthened claims
repository-computed dependency edges and proof closures
counterexample and abstraction evidence
split proposal and research-ledger validation
maturity-derived next route
immutable A2 admission replay
```

## Failure boundary

```text
inflated self-reported counters rejected
claim-set re-identification with inconsistent delta rejected
missing inventory evidence rejected
cross-paper task identities kept distinct
no-progress and blocked outcomes routed separately
completed events checked for exact role, context, task, result, paper, and program identity
```

The ordinary `paper-ci` workflow compiles the Agent CLI with warnings as errors and runs these checks together with the existing portfolio, A0/A1, audit, frontier, certification, exact-release, and C-pipeline regressions.
